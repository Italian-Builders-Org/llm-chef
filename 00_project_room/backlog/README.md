# Backlog

This folder holds deferred work that may become GitHub issues later.

Backlog is not active scope. It is a parking lot for ideas that should be preserved without distracting from V1.

## Rule

Do not convert backlog items into GitHub issues until:

1. The V1 product option is selected.
2. The item has a clear owner or milestone.
3. The issue has success criteria and an explicit out-of-scope section.

## Status Values

- `deferred_post_v1`: intentionally later than the first website MVP.
- `needs_decision`: requires team discussion before any work.
- `candidate_issue`: ready to become a GitHub issue once GitHub is connected.
- `active`: moved out of backlog into current scope.
- `rejected`: intentionally not pursuing.
