# Evaluation Questions

Status: Draft.

## What A Model Must Prove

1. Can it answer with source citations?
2. Can it distinguish source text from editorial interpretation?
3. Can it say "not found" when the corpus lacks evidence?
4. Can it map old terms and units without hallucinating precision?
5. Can it compare recipes across sources and periods?
6. Can it help produce Level B interpretations without fabricating details?
7. Can it support Level C executable recipes while labeling changes?

## Baseline

Before fine-tuning, test ordinary retrieval-augmented generation over a small verified corpus. If RAG solves the job, fine-tuning may be unnecessary.
