# Taxonomy Seed

Status: Draft from attached historical classification and screenshots.

## Source-Level Axes

- historical period
- publication year
- author/editor
- language
- country/region
- culinary movement
- source type
- intended audience
- public domain / rights status

## Historical Period Seed

- Pre-Unification and early 19th century
- Late 19th century / national codification
- Turn of the century / nutrition, industry, ingredients
- Interwar period
- Mid-20th century
- Late 20th century
- Renaissance / 1400-1600, pending source verification

## Source Type Seed

- technical / professional
- didactic
- scientific / medical / nutrition
- ingredient-focused
- gastronomic and cultural
- regional and historical

## Recipe-Level Axes

- source book
- page/reference
- original title
- normalized title
- original language
- region
- period
- ingredients
- techniques
- cooking method
- use/function: daily, feast, medical, preservation, ritual, other
- measurement system
- unit type
- precision level
- historical unit reference
- editorial level

## Dosing And Units Seed

Measurement system:

- no dose / procedural
- qualitative dose
- historical local units
- modern metric
- Anglo-Saxon
- mixed / incoherent

Unit type:

- weight
- volume
- discrete quantity
- time
- sensation/perception

Precision level:

1. Procedural - craft knowledge, no measurement.
2. Indicative - vague doses, experience required.
3. Semi-structured - some measures present.
4. Structured - measures mostly complete.
5. Modern - fully measured.

## Editorial Level Seed

- Level A: original historical recipe.
- Level B: guided editorial interpretation.
- Level C: standardized executable version.
