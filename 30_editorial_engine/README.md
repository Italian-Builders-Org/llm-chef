# Editorial Engine

Purpose: define how historical recipes become readable content without falsifying the source.

This room owns:

- editorial playbook
- recipe templates
- modernization rules
- measurement interpretation policy
- examples of original vs interpreted vs executable recipes

This room does not own source rights, database schema, frontend UX, or model experiments.

## Local Map

| Folder | Purpose | Status |
|---|---|---|
| `playbook/` | Editorial playbook and layering rules. | active |
| `templates/` | Recipe presentation templates. | create on demand |
| `examples/` | Original vs interpreted vs executable samples. | create on demand |

Add subfolders per `FOLDER_MAP.md` (Subfolder Creation Rule); update this table in the same change.

## First Principle

Historical recipes should not be silently normalized. If the team changes dose, method, timing, ingredient availability, or language, the change must be labeled.
