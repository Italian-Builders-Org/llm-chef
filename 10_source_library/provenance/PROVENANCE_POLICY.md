# Provenance Policy

Status: Draft. Not approved.

## Principle

Every source must have provenance before it is used for public output, model training, or publishing.

## Minimum Source Record

- title
- author/editor if known
- author death year if known
- year or year range
- original publication year
- edition year
- publisher if known
- physical/digital origin
- source URL or physical-copy reference
- scan/source provider
- provider license or terms URL
- scan owner
- file location
- rights/public domain status
- jurisdiction checked (EU/Italy, US, other if relevant)
- cultural heritage or public-collection constraints
- separate rights notes for translations, introductions, annotations, images, or later editorial material
- allowed uses
- citation format
- public release reviewer
- public release review date

## Allowed Uses

Use these labels until a better policy exists:

- `metadata_only`
- `private_research_only`
- `internal_extraction_allowed`
- `public_domain_likely`
- `public_domain_verified`
- `permission_needed`
- `do_not_use`

## Open Questions

- Which sources are family-owned scans?
- Which sources came from public internet PDFs?
- Which sources are under copyright in Italy, the US, or both?
- Can OCR text be committed if the PDF cannot?
- Can structured facts from copyrighted books be stored separately?
